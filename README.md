# SOVRA VPN - Next-Gen Android Client

SOVRA VPN is a high-performance, neon-themed Android VPN application powered by the latest **Xray-core**.

### Key Architectural Highlights:
- **Core Engine:** Xray-core (Full support for `xhttp`, `reality`, `vless`, `vmess`, `trojan`, `shadowsocks`).
- **Smart Cloudflare Scanner:** Real throughput and download rate testing to find the cleanest Cloudflare IP for Iranian ISPs (MCI, Irancell, Rightel, Fixed Line).
- **Dual Connection Modes:** 
  - ⚡ *Low Latency (Gaming & Calling)*
  - 🚀 *High Speed (Maximum Throughput for Streaming/Downloads)*
- **Static IP Mode:** Guaranteed fixed exit IP for sensitive operations (Trading, Freelance).
- **Security & Anti-Abuse:** Hardware device fingerprinting to prevent free trial abuse (persistent across app reinstalls).
- **In-App Store:** Direct card-to-card receipt submission with real-time verification and zero-touch renewal.
- **Offline First:** Cached configs and independent VPN routing.
